# DESIGN.md — DevelopmentRAGEnvironment のチャット画面(Cloudflare Worker)の見た目の決めごと

新しい画面や部品を足す(AI に頼む場合も)ときは、この文書を渡す。値の出どころは `src/chatUi.ts`(画面は、CSS と JS を内蔵した 1 つの HTML 文字列。`/` と `/chat` で配信)。食い違ったらコードを正とし、この文書を直す。画面の全体の決めごと(U1 など)は [../IMPROVEMENT_DESIGN_2026-10.md](../IMPROVEMENT_DESIGN_2026-10.md)。

背景: [QUALITY_UPLIFT_2026-11-09.md](../../QUALITY_UPLIFT_2026-11-09.md)(QL1〜QL3)。共通の考え方は [Web/Portfolio/DESIGN.md](../../Web/Portfolio/DESIGN.md)。これは**運用に近いツール**(層 G0〜G1 + 見せ場 1 つまで。見せ場はチャットのヒーロー)。**管理タブに重い演出を置かない**。画面は 5 タブ(チャット・グラフ・履歴・お気に入り・管理)で、**管理タブは役割で出し分ける**(サーバー側で認可)。

## 1. 方針

- 黒に近い地・単色の差し色・影なしのフラットな見た目(Dala スタイルガイドを基にした)。
- 情報密度が高い機能的な画面。大見出し・装飾は持ち込まない。区切りは 1px の細い線(フォームと表だけ)。
- **文字に使う色と、塗りに使う色は、別のトークン**にする(§2)。

## 2. 色(2 テーマ)

### 2.1 コントラスト(2026-11-11)

基準: 通常の文字 4.5:1 以上(WCAG 2.x AA)。**文字に使う色は、地・パネル・吹き出しのどの上でも 4.5:1 以上**、塗りの上の文字も 4.5:1 以上、を**トークンの全組み合わせで保証**し、`test/ui_contrast.test.mjs` が両テーマ(ライトは手動・自動の 2 か所)を毎回検査する。

## 3. 動き

1. **既存の動きは、それぞれの時間を持つ**。書き換えない。**これから足す動き**は、`chatUi.ts` のトークンを使う: `--dur-instant` 120ms・`--dur-open` 240ms・`--dur-enter` 300ms、`--ease-out` / `--ease-in` / `--ease-move`。動かす性質は `transform` と `opacity`。**1 画面の動きは 2 種類まで**(チャット = タイプライター + ドロワー。管理 = スクロールスパイ)。
2. **動きを減らす設定**: CSS の動きは、`@media (prefers-reduced-motion: no-preference)` の中だけに書く(reduce では動かない)。JS の動きは `matchMedia("(prefers-reduced-motion: reduce)")` を見る(タイプライター・ASCII アート・**ヒーローのパーティクル**)。
3. 無限ループは 3 つ: `pulse-soft`(処理中のスケルトン・no-preference の中)・`progress-slide`(終わりが読めない処理の帯)・ヒーローのパーティクル(canvas)。**新しい無限ループは足さない**(読み込み中を除く)。
4. **2026-11-11 に直したもの**: ① `progress-slide` は reduced-motion の対象外で、`margin-left`(レイアウト)を動かしていた → `transform` に直し、reduce では止める。② ヒーローのパーティクルは reduced-motion を見ていなかった → reduce では 1 フレームだけ描いて止める(`heroCalm`。ブラウザでの実行は未確認。構文とコードの形をテストで確認)。
5. 未使用の `@keyframes drift` が残っている(使われていない)。

## 4. アイコン

- **マーク**: 暗い角丸の正方形に、太さ 2.6 の「R」と、琥珀の点(出典の印。`--highlight` と同じ色)。`icon.svg` は、ブラウザが暗いときは明暗が反転する。
- **配信**: Worker が認証なしで返す(`src/index.ts`)。`/icon.svg`・`/favicon.ico`(16 / 32 / 48px)・`/apple-touch-icon.png`(180px)。画像は `src/siteIcons.ts` の定数(base64)で、`<head>` の `<link>` から読む。以前は `/favicon.ico` に中身なしの 204 を返していた。
- **作り直すとき**: 同じ図形から 3 つとも作る。`test/site_icons.test.mjs` が、ICO の構造(16 / 32 / 48 の PNG)・PNG(180×180)・SVG に外部参照が無いこと・ルートが認証より前で content-type が正しいことを検査する。
- **作らないもの**: OGP と PWA のマニフェスト(認証が要る内部ツール)。
