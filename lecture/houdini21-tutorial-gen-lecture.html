実装

Cloud RAG検索モードを追加

これまでLocal RAG（rag_local_bridge.py）のみだった検索元に、GAS WebApp（gas_cloud_rag.js）経由のCloud RAGを追加した。CloudRAG側にドキュメントが多く蓄積されている運用実態に合わせた対応。

  • mode:'raw' で最終回答生成（Gemini呼び出し）をスキップし、検索結果だけを軽量取得
  • 取得後に db=="houdini21" 以外を除外し、ホワイトリストをクライアント側でも強制
  • 既存のSettingsタブ（mode / gas_url / gas_api_key）を再利用、新規UIなし

05 / 08
原因分析と修正

2つの独立したレバーを調整

- MODEL = "claude-sonnet-4-6"
- MAX_ITERATIONS = 25
+ MODEL = "claude-sonnet-5"
+ MAX_ITERATIONS = 40
  • MAX_ITERATIONS 25→40: 単純に反復の余裕を増やす
  • MODEL Sonnet4.6→Sonnet5: agentic性能向上で反復効率UP、かつ導入価格が安い（$2/$10 vs $3/$15 per MTok）— 性能とコストを両取り
