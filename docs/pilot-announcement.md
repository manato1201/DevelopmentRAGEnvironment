## A. プロフェッショナルの方へ（レビューのお願い）

**対象:** TA 専門の企業の方、SideFX 社の方

**件名:** 【レビューのお願い】Houdini のチュートリアル自動生成システムについて

〇〇 様

Houdini のチュートリアルを、AI が実際にノードを組みながら自動で作るシステムを、卒業研究として開発しています。学生による実証実験と並行して、**実務の観点から、専門家のレビューをお願いしたく**、ご連絡しました。

**システムの概要**
- Houdini 上のパネルに、作りたいもの（例:「煙のシミュレーション」）を入力すると、Houdini の公式ドキュメントを検索し、実際にノードを組んで、**動作確認済みのチュートリアル**を作ります。
- 回答・チュートリアルには、**どの資料を使ったか（出典）**を付けます。
- 説明の深さは 3 段階（basic / applied / advanced）で、利用者の使う用語に合わせて自動で変わります。

**お願いしたいこと**
1. システムの概要とデモを、ご覧ください。
2. 生成されたチュートリアル **5〜10 本**を、読んで（可能なら再現して）ください。
3. 次の観点で、5 段階の評価と、自由記述をお願いします。
   - **実務の流れに導入する価値**
   - **品質**: 正確性（ノード・パラメータが実在し、正しいか）／再現性（手順どおりに動くか）／難易度への適合／構成のわかりやすさ／安全性（危険な操作がないか）。重大な誤りは、別にお知らせください。

**ご確認事項**
- 評価の入力用に、シート（表）をお送りします。所要は、1 本あたり約 10 分を想定しています【概算】。
- お送りする資料に、**参加した学生の質問文・個人情報は含みません**。
- 生成物は、**SideFX の公式ドキュメントをもとに作った内容**です。資料には出典を付けます。
- 論文・発表に、**社名・コメントを掲載してよいか**、事前にご確認させてください【要記入: 掲載の可否・引用の許可】。
- ご回答の期限: 【要記入】（目安: 11 月下旬までに、解析・論文執筆に入るため）

お忙しいところ恐れ入ります。ご検討をお願いいたします。

## B. 学生（ビギナー）向け

**件名:** Houdini の勉強に使える AI ツールの「お試し」に参加しませんか（実証実験）

Houdini を学び始めたみなさんへ。

Houdini の中で、作りたいものを入力すると、AI が**手順つきのチュートリアル**を作ってくれるツールを開発しています。**勉強の助けになるか**を確かめるため、参加してくれる方を募集します。

**参加すると、何をするのか**
- **3 回**（各回は 1 週間ほどの期間の中で、都合のよい日に）、次の 2 つの課題をします。
  - **固定課題**: 回ごとに題材が変わります。**Pyro（煙・炎）／RBD（剛体・破壊）／雲（パーティクル）**。作品物ができたら、完了です。
  - **自由課題**: 自分が作りたいものを、自由に。
- **3 回のうち 1 回は、固定課題を「公式ドキュメント・Web 検索のみ」で行います**（ツールを使わない回。ツールと比べるためです。どの回かは、運営がお伝えします）。
- 最初に 1 回、**事前アンケート**（Houdini の経験など。氏名などは聞きません）。各課題のあとに、**短いアンケート**（難しさ・わかりやすさなど。**答えたくない項目は、空欄で大丈夫です**）。
- 課題は、Houdini のパネルの「**課題**」タブで、開始・終了を押すだけです。かかった時間などは、自動で記録されます。

**できること（ツール）**
- チュートリアルを、3 つの段階で作れます。**basic**（やさしく）／**applied**（動かして理解）／**advanced**（仕事で使える形に）。
- チャットで質問できます。**どの資料を使って答えたか**が表示されます。「おまかせ」にすると、使う用語が増えるにつれて、説明が少しずつ専門的になります。

**安心してほしいこと**
- **成績とは関係ありません。**参加しなくても、不利益はありません。途中でやめることもできます。
- 結果は、氏名ではなく**番号（P01 など）**で集計します。【要記入: 詳しい取り扱い（§4）】
- 評価は、**ツールの出来を見るもの**で、あなたの腕前を見るものではありません。
- Houdini は、**Apprentice（無料）**で大丈夫です。

**必要なもの**
- Houdini 21 または 22（Apprentice 可）。Windows 10 / 11。インターネット接続。
- 運営から渡す **URL と API キー**（お 1 人に 1 つ。他の人には見せないでください）。

**お願い**
- **個人情報・秘密にしたい情報は、質問や課題に入力しないでください。**
- AI が作った内容には、誤りがありえます。**必ず自分で確認してください。**

**期間・申し込み**
- 第1回 11/4〜11/6／第2回 11/11〜11/17／第3回 11/18〜11/24（**11/7〜11/10 はお休み**）。具体的な日は、相談して決めます。
- 1 回あたりの所要: 【要記入】／申し込み: 【要記入】（締め切り 11/2）／質問: 【要記入】
- 同意書: 【※準備中。できてから告知】

## 4. データの扱い（現在の仕組みから書いた案。公開前に確認してください）

参加者に聞かれやすい点を、**いまの実装**から整理しました。実際の運用ルールと食い違わないか、確認してから使ってください。

| 聞かれること | 現在の仕組み |
|---|---|
| 入力した質問・回答は残る？ | 質問と回答は、運営の Worker に**履歴として保存**されます（本人は履歴タブで見られます）。**保存期間は未決定**【要記入】。 |
| 運営から質問の中身が見える？ | **要確認。**質問の監査ログは内容をハッシュ化して記録していますが、履歴には本文が保存されています。運営（管理者）が本文を見られる範囲を、決めて書いてください。 |
| 課題では、何が記録される？ | **開始・終了の時刻（所要時間）、その間の質問の回数、cook エラーが出たノードの「数」、到達（作品物ができたか）、アンケートの回答**です。ノードの名前やパスは、送りません（数だけ）。 |
| 「成長」で何が記録される？ | **専門用語と回数だけ**です（質問の文章は保存しません）。本人は、パネルの「接続」タブで見られ、**いつでも消せます**。 |
| 誰が、何をしたか分かる？ | 課題の集計は、**氏名ではなく番号（P01 など）**で出します。ただし、API キーごとに利用量・評価が記録されるので、学生は**匿名の ID** のキーにする運用が必要です。 |
| 公式ドキュメントのみの回に、ツールを使ったら？ | その回の時間内に質問が記録されると、**「ツールを使った可能性」として確認されます**（分析から外すかを、検討するため）。責めるためではなく、比較を正しく行うためです。**参加者にも、あらかじめ伝えます。** |
| 間違えて「終了」を押したら？ | 「終了して振り返りへ」のあとの画面で**「戻る」**を押せば、課題は続いたままです。送信したあとでも、**「完了した記録」の「やり直す」**で取り直せます（次の回を始めるまで）。計測中は**「計測をやり直す」**で最初からやり直せます。やり直した前の記録は集計に入りませんが、**やり直した回数は運営に残ります**。 |
| Houdini が落ちたり、閉じたりしたら？ | 課題の記録は残ります。開き直して**「続きから開始」**を押してください。閉じていた時間は作業の時間に入れません。 |
| 課題の記録を、あとから消せる？ | **本人が消す機能は、まだありません**（やり直しで破棄しても、運営側には「破棄した記録」として残ります。成長の記録は、本人が消せます）。【要確認: 消去の依頼を、運営が受ける運用にするか】 |
| 費用は誰が払う？ | AI・音声の利用料は**運営が負担**します。キーごとに**予算の上限**があります（目安: 1人 420,000 トークン。チュートリアル約10回分）。 |
| 動画は公開される？ | 動画ギャラリーへの**アップロードは、本人の操作**です。公開範囲は【要記入】。 |

**参加者への注意として、必ず書くこと**
- 社外秘・個人情報を入力しない。
- AI が作った内容は、**必ず自分で確認する**（誤りがありえます）。
- API キーは、他の人に見せない。
- 公式ドキュメントのみの回は、このパネルのチャットとチュートリアル生成を使わない。
