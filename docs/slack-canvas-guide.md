# RAGボットの使い方

Houdini などの資料をもとに、質問に答えるボットです。回答には**出典**が付きます。

## 1. 最初に（1回だけ）：自分のアカウントとつなぐ

1. [Web 画面](https://rag-poc.manato1201m.workers.dev) を開き、APIキーを入れます。
2. 「**自分用の連携**」→「**Slackから質問する**」→「**連携コードを発行**」を押します。
3. Slack で、次のように送ります（コードは **10分以内・1回だけ**使えます）。

`/rag link コード`

「連携しました」と出れば完了です。APIキーを Slack に貼る必要はありません。

## 2. 質問のしかた

| 方法 | 使い方 | 答えが見える人 |
|---|---|---|
| **メンション** | このチャンネルで `@System-Notification 質問` | スレッドの全員 |
| **DM** | ボットに、そのまま質問を送る | あなただけ |
| **スラッシュコマンド** | `/rag 質問文` | あなただけ |

- メンションの返事は**スレッド**に付きます。続けて同じスレッドで聞くと、前のやり取りをふまえて答えます。
- DM は、直近のやり取りをふまえて答えます。
- 答えが出るまで、数秒〜十数秒かかります。まず「調べています…」と出ます。
- `/rag unlink` で連携を解除できます。`/rag help` で使い方が出ます。

## 3. 質問の例

- `@System-Notification TOP って何ですか？`
- `@System-Notification SOP と DOP の違いは？`
- `@System-Notification PDG で、変更があった部分だけ再計算するにはどうする？`
- `@System-Notification VEX で、ポイントの位置をずらすサンプルを教えて`

コツ: **作りたいもの・使っているノード・困っていること**を書くと、答えが合いやすくなります。

## 4. 答えられること・答えられないこと

**答えられること**
- 登録してある資料（Houdini 21・22 のドキュメントなど）に書いてあること。
- 回答の下の **出典** で、元の資料を確認できます。見方は次のとおりです。
  - 「**回答で使った資料: 3件（検索で見つかった5件のうち）**」… 回答の中で `[1]` `[2]` と引用された資料です。番号は、回答の文中の番号と対応します。
  - 「引用2回」… 同じ資料を、回答の中で何度も根拠にしたことを表します。
  - 「回答では使わなかった資料」… 検索では見つかりましたが、回答には使われなかった資料です。
  - 「**回答の中で、資料の番号による引用がありませんでした**」と出たときは、出典を示さずに答えている可能性があります。必ず資料で確認してください。

**答えられない・注意すること**
- **資料に無いことは、答えられません**（または、不確かな答えになります）。必ず出典を確認してください。AI の回答は、間違うことがあります。
- **チャンネルでは、外部サービス（GitHub・メール・予定など）は使いません。** その場の全員に見えるためです。外部サービスを使う質問は、DM で聞きます（Web 画面で接続を済ませた人だけ）。
- **Slack からは、書き込みや実行はできません**（メッセージの送信、ファイルの変更など）。
- 質問の回数・使える量には、**人ごとの上限**があります。上限に達すると、「質問できませんでした」と出ます。
- 連携していない人の質問には、連携の手順だけが返ります。

## 5. 困ったとき

| 表示 | 対処 |
|---|---|
| まだ連携されていません | 「1. 最初に」の手順をやり直す |
| 連携コードが無効か、期限が切れています | Web 画面で、コードを発行し直す（10分・1回限り） |
| このSlackワークスペースは、まだ利用が許可されていません | 管理者に連絡する |
| 質問できませんでした: … | 少し待って、もう一度送る。続く場合は、表示された内容を管理者に伝える |
