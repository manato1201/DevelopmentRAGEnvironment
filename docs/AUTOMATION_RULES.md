# 自動化の運用ルール(R8)

自動化(チュートリアル生成・同期・MCPツール)の暴走を防ぐため、やること/やらないこと/成果物を固定する。

## やること
- 変更前に監査ログ(JSONL)へ判断と確率を残す。
- 破壊的でない操作(検索・読み取り・下書き生成)は自動で実行してよい。
- トークン予算(RAG/Claude)を超える前に停止し、残量を表示する。
- 外部入力を含む操作は、サンドボックス化した実行環境から始める(Houdini実行部は別扱い)。

## やらないこと(人かルールの承認が必要)
- 送信(メール・Slack通知など)、削除、ロールバック、権限変更を自動判断で実行しない。
- 判断モデルの出力だけで最終決定しない。
- APIキー・トークンをログやチャットに平文で出さない。

## 成果物
- 生成物は `docs/` または所定のバックアップ先に保存し、実行ログ(JSONL)と対応づける。
- 精度・コストを測った結果は、実測値と条件(データセット・モデル・日付)をセットで残す。
