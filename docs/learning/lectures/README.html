Part 2: アルゴリズムとスクリプト（第11〜16回）

第1〜10回は「全体の仕組み」でした。Part 2 は、関数の中身（アルゴリズム）と、スクリプトを、数を入れて検算しながら読みます。本文の数値は、すべて実際にコードを動かして確かめた値です（再確認の方法は下の「数値の再確認」）。

回 題 身につくこと 目安
第11回 アルゴリズムの読み方・書き方（基礎） トレース表・計算量・Map/Set・安定ソート・純関数・正規表現（先読み／後読み）を、実コードで説明できる 3時間
第12回 検索のアルゴリズム 分割・ベクトル・BM25・RRF の手計算・HyDE・章の絞り込み・namespace の間引き。検索がおかしいとき、どの段を疑うか言える 4時間
第13回 制御のアルゴリズム 認証のハッシュ・回数制限・予約→実行→清算の予算・TOCTOU・タイムアウト・SSE・UPSERT。失敗したとき何が戻るか言える 4時間
第14回 グラフのアルゴリズム 最大剰余法・類似度のエッジ・鎖の折り畳み・Kahn 法・層配置（Sugiyama 風）・時間予算つき走査 4時間
第15回 実験設計と習熟度の数式 ラテン方格・所要時間の式・操作ミスのスコア・中央値・順位相関・習熟度の点・k-匿名。式を変えるときの注意 4時間
第16回 スクリプトを読み・書く 安全なスクリプトの型・deploy_panels.py・diagram_kit.py・build_docs_html.py・新しいスクリプトの書き方 4時間

読む順序: 第11回 → 第12・13・14・15回（どの順でも可。第12 → 13 が自然）→ 第16回。第12・13回は第5回、第15回は第8回、第16回は第9回を前提にします。

Part 2 の演習の特徴: ①手計算してから、コードを動かして確かめる。②「読み取り練習」（第13回 §2.5 など）は、実際に見つかった癖を題材にしている。③テストを足す演習（第14回 演習 14.7、第16回 演習 16.4）は、現状でテストが無い箇所を、保守の練習として埋める。

学び方

  1. 順番に読む。 第1〜4回は、どの順でも構いませんが、第5回以降は、前の回を前提にします。
  2. 手を動かす。 各回の「演習」は、実際にこのリポジトリのファイルを開いて答える形です。答えは、各回の末尾の「解答の方針」で確かめます（答えそのものより、どこを見れば分かるかを書いてあります）。
  3. 本番に触れない。 演習は、--remote を付けない（ローカルの開発用 DB）か、読み取りだけです。本番を変える操作（マイグレーション・デプロイ）が出る回では、必ず「これは本番を変える」と明記します。
  4. コメントを読む。 このリポジトリのコードのコメントには、実際に起きた問題と、その対策が書いてあります。設計を変える前に、読んでください。
