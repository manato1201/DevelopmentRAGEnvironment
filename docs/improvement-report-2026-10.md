## UIパーツ・Motion 追補(2026-10-11)の実施

| 種別 | 内容 | 状態 |
|---|---|---|
| ドロワー(02)/ボトムシート(03) | 出典の詳細(本文の抜粋・関連度・namespace・引用回数)を右から出す。狭い画面は下から | 実装・ブラウザ確認済み |
| スケルトン(21) | 回答の生成中に、回答の形の灰色の枠(動かさない) | 実装(スタブが即答のため、枠の表示そのものは目視していない) |
| トースト(08) | 評価・コピー・お気に入り・同期の完了と失敗 | 実装済み |
| チップ(13) | チャットの検索対象namespaceを、押して付け外し(複数選択可) | 実装・ブラウザ確認済み |
| バッジ(23) | 直近7日の同期の失敗件数(管理タブ・ナレッジ登録) | 実装・ブラウザ確認済み |
| エンプティステート(24) | 履歴・お気に入りが無いとき、次の行動を案内 | 実装・ブラウザ確認済み |
| タイプライター(07) | 新しい回答の文字を最大1.5秒で順に表示 | 実装・ブラウザ確認済み(最終表示が完全な文であること) |
| スクロールスパイ(24) | 管理タブの左に見出しの一覧、現在地をハイライト | 実装・一覧の生成を確認(スクロールでのハイライトは未確認) |

- 動きは「チャット = タイプライター + ドロワーの出入り」「管理 = スクロールスパイ」の2種類以内。前回の波紋と空状態の漂いは外した。すべて `prefers-reduced-motion` で止まる。
- `/query` のレスポンスの `sources[].excerpt` を追加した(/search には付けない)。

## 追加の修正(2026-10-14)

| 項目 | 内容 |
|---|---|
| 再クロールの停止 | 変更の無いページを飛ばす（本文ハッシュ）、1ページごとの時間の上限、通信失敗の自動再試行、中断したクロールの一覧と「続きから再開」。D1への書き込みをバッチにまとめ、再登録で短くなったページの古い末尾を消す |
| グラフの上限 | 表示ノードを最大500件に。namespaceごとの文書数の比率に合わせて抜き出す。エッジの重複判定とベクトルの取得も効率化 |
| 見直しで直したもの | 他のユーザーの個人用namespaceへ手動の取り込みができてしまう点を拒否 / 取り込み種別のアイコンが空で描かれる不具合（YouTube） / 未使用のimport / MCP本人専用の接続の検索のダミー値 / ユーザー削除時に再クロールの記録も消す |
