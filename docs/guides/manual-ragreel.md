# RAGReel（動画生成）取扱説明書

**対象:** 実証実験に参加する方、運営 ／ **版:** RAGReel 1.1.0（2026-10-21）／ 技術的な詳細は、RAGReel リポジトリの `docs/technical-reference.md`

## 1. これは何か

[![動画ができるまで（RAGReel）](../images/05-video-flow.svg)](../images/05-video-flow.svg)

*図: 動画ができるまで（RAGReel）。手順書から、音声つきの WebM を作り、ダッシュボードに載せる。*

Houdini チュートリアル（手順書＋スクリーンショット＋初心者向けの台本）から、**説明つきの解説動画**（`.webm`）を作るツールです。

| 実行ファイル | 役割 | 使う人 |
|---|---|---|
| `video_factory_cloudrag_poc.exe` | 動画生成エンジン（本体）。**Houdini のパネルが、自動で起動します。** | ほとんどの方は、直接触りません |
| `RAGReel.exe` | 画面つきのランチャー。保存済みの手順書（`.md`）から、動画を作り直せます。 | 動画だけ作り直したいとき |

**普通は、Houdini のパネルで「保存」を押すだけで、動画が作られます**（[manual-houdini-tutorial.md](manual-houdini-tutorial.md) §7）。このマニュアルは、インストールと、トラブルのときのためのものです。

## 2. インストール

1. 配布された **`RAGReel-Setup-1.1.0.exe`** を実行します。
2. 「Windows によって PC が保護されました」と出たら、「**詳細情報**」→「**実行**」を押します（このインストーラーは、まだ署名されていないためです）。
3. 「**自分だけ**」（このユーザーのみ）を選んで、あとは「次へ」。管理者権限は要りません。
   - 「すべてのユーザー」を選ぶと、`C:\Program Files` に入り、**動画の保存で権限エラーになることがあります**。選ばないでください。
4. 完了です。インストール先は、`C:\Users\<あなた>\AppData\Local\Programs\RAGReel` です。

- **Visual C++ の追加インストールは、要りません**（必要な DLL を同梱しています）。
- **VOICEVOX も、要りません**（音声は、運営のサーバー経由です）。
- 更新は、新しいインストーラーを実行するだけです。作った動画は消えません。

## 3. Houdini と一緒に使う

[manual-houdini-tutorial.md](manual-houdini-tutorial.md) の導入（`install.cmd`）を実行すると、**インストール済みの RAGReel の場所を自動で見つけて**、パネルの設定（`video_factory_exe_path`）に書きます。RAGReel を**あとから**入れたときは、`install.cmd` をもう一度実行するか、パネルの Settings タブで、`video_factory_cloudrag_poc.exe` のフルパスを入れてください。

パネルは、保存のあと、動画エンジンを起動し、**接続先の URL と API キー**を、環境変数で渡します（コマンドラインには出しません）。音声は、そのキーで、運営のサーバーから取得します。

## 4. 画面つきランチャー（RAGReel.exe）

スタートメニューの「RAGReel」から起動します。

| タブ | できること |
|---|---|
| はじめに | 使い方の3ステップと、困ったときのヒント |
| 設定 | 接続先（Cloud RAG）の URL と API キー。保存されます |
| Cloud RAG クエリ | 質問文から、動画を作る（Cloud RAG 版。実証実験では使いません） |
| Houdini チュートリアル | **保存済みの手順書（`.md`）を選んで、動画を作り直す** |

下に、実行ログが出ます。右上のランプは、接続の状態です。

- 手順書と同じ場所に、同名の `.json`（ノードグラフ）と `_screenshots.json`（スクリーンショットの一覧）、`_video_script.json`（台本）があれば、自動で使います。**台本があると、初心者向けの説明つきの動画になります。** 無いと、手順書の朗読になります（台本は、Houdini のパネルが作ります）。

## 5. 動画の保存先

| もの | 場所 |
|---|---|
| 動画（`.webm`） | インストール先（`...\Programs\RAGReel\`）と、`output\videos\<実行ID>\` |
| 一覧のページ | `output\index.html` をブラウザで開く |
| ログ | 手順書と同じフォルダの `<名前>_video_factory.log`（Houdini から作ったとき） |

## 6. 音声

| 優先順 | 音声 | 条件 |
|---|---|---|
| 1 | **Google の音声合成**（運営のサーバー経由） | 接続先の URL と API キーがある（Houdini のパネルが渡します）。1日の文字数の上限あり |
| 2 | VOICEVOX（春日部つむぎ） | 手元に VOICEVOX が入っている（止まっていれば、自動で起動します）。公開するときは「VOICEVOX:春日部つむぎ」のクレジットを入れてください |
| 3 | Windows 標準の音声（SAPI） | どちらも使えないとき。品質は低めです |

ログの `Narration voice:` の行に、実際に使われた音声が出ます。

環境変数 `RAGREEL_TTS_BACKEND`（`auto` / `cloud` / `voicevox` / `sapi`）で、固定できます（通常は `auto`）。

## 7. 進み具合

動画エンジンは、ログに進み具合を出します。Houdini のパネルは、これを読んで、プログレスバーに出します。

- `Narration progress: k / n` … 音声の作成（スライドごと）
- `Rendered frame N / M` … 描画
- `Wrote ….webm` … 完了

## 8. 困ったとき

| 症状 | 対処 |
|---|---|
| 起動しない（DLL が無い、のようなエラー） | 最新のインストーラー（1.1.0 以降）で入れ直してください。 |
| インストーラーが「パスが見つかりません」で止まる | インストール先のパスが長すぎます（260文字の上限）。短い場所（例: 既定の場所）にしてください。 |
| 動画の保存でエラー | 「すべてのユーザー」で `Program Files` に入れた場合に起きます。「自分だけ」で入れ直してください。 |
| 音声が従来の音声（SAPI） | URL と API キーが入っているか、1日の上限に達していないか、ログの `Narration engine:` の行を確認。 |
| 説明が手順書の朗読になる | `_video_script.json` が、手順書と同じ場所にあるか確認。無ければ、Houdini のパネルで保存し直すと作られます。 |
| 動画が作られない | ログ（`_video_factory.log`）の最後の `ERROR` / `WARNING` の行を、運営に送ってください。 |
| ウイルス対策ソフトに止められる | `RAGReel` のフォルダを、除外に追加してください（未署名のため、誤検知されることがあります）。 |

## 9. アンインストール

Windows の「設定 → アプリ → インストールされているアプリ」から、RAGReel を削除します。**作った動画（`output\videos\` と `.webm`）は、削除されずに残ることがあります。** 不要ならフォルダごと削除してください。

## 10. ライセンスと表記

- 動画エンジンは、Qt（LGPL）と FFmpeg（LGPL）を、**動的リンク（DLL）**で使っています。
- VOICEVOX の声を使った動画を**公開**するときは、「VOICEVOX:春日部つむぎ」のクレジットが必要です。Google の音声では不要です。
- Houdini の画面を含む動画の公開は、各自の Houdini のライセンス条件に従ってください。
