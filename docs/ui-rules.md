# UI 決めごと表(chatUi.ts)

出典: [IMPROVEMENT_DESIGN_2026-10.md](../IMPROVEMENT_DESIGN_2026-10.md) 第3章(2026-10-08 に Phase 0 として固定)

| 項目 | 決め |
|---|---|
| アイコン | 線幅1.5pxの1セットのインラインSVGのみ(`iconEl()`)。絵文字(👍/👎/✓/★)は使わない |
| 矢印 | 開閉は下向き(開くと上向き)、遷移は右向き。展開矢印を右向きのまま放置しない |
| 数字 | 半角。トークン数・件数・関連度は `font-variant-numeric: var(--font-num)`(等幅数字) |
| 行の構造 | 見出し1行 + 灰色の小さい副題1行(`--row-sub`)。1行に2情報を詰めない |
| 本文 | 左端を揃える。字下げ用の全角スペースは使わない |
| 絵文字 | 画面の見出し・ボタンには使わない |
| 色 | 新しい色は追加しない。既存のCSS変数のみ。追加トークンは `--font-num` と `--row-sub` だけ |
| テーマ | `data-theme="light|dark"` で手動指定、未指定=自動(OS設定に追従)。選択は localStorage `ragPocTheme`(例外は握りつぶす) |
| 動き | 空状態など小さな演出だけ。すべて `prefers-reduced-motion` で止める |
| 実装上の制約 | テンプレートリテラル内JSは `\n` のように改行エスケープを2重にする。`innerHTML` に未検証の文字列を渡さない |
