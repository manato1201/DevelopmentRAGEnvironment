# UI 決めごと表(chatUi.ts)

出典: [IMPROVEMENT_DESIGN_2026-10.md](../../IMPROVEMENT_DESIGN_2026-10.md) 第3章(2026-10-08 に Phase 0 として固定)

| 項目 | 決め |
|---|---|
| アイコン | 線幅1.5pxの1セットのインラインSVGのみ(`iconEl()`)。絵文字(👍/👎/✓/★)は使わない |
| 矢印 | 開閉は下向き(開くと上向き)、遷移は右向き。展開矢印を右向きのまま放置しない |
| 数字 | 半角。トークン数・件数・関連度は `font-variant-numeric: var(--font-num)`(等幅数字) |
| 行の構造 | 見出し1行 + 灰色の小さい副題1行(`--row-sub`)。1行に2情報を詰めない |
| 本文 | 左端を揃える。字下げ用の全角スペースは使わない |
| 絵文字 | 画面の見出し・ボタンには使わない |
| 色 | 新しい色は追加しない。既存のCSS変数のみ。追加トークンは `--font-num` と `--row-sub` だけ |
| テーマ | `data-theme="light|dark"` で手動指定、未指定=自動(OS設定に追従)。選択は localStorage `ragPocTheme`(例外は握りつぶす) |
| 動き | **1画面で使う動きは2種類まで**(チャット = タイプライター + ドロワーの出入り / 管理 = スクロールスパイのハイライト)。通常画面は静かに保ち、スケルトン・空状態の点は動かさない。すべて `prefers-reduced-motion` で止める。撮影の決定性や安全上限が要る画面では動きを使わない |
| 実装上の制約 | テンプレートリテラル内JSは `\n` のように改行エスケープを2重にする。`innerHTML` に未検証の文字列を渡さない |

## UIパーツ・動き(2026-10-11、IMPROVEMENT_DESIGN_2026-10.md 追補)

指示の書き方は「名前 + 場所・きっかけ」(例: 出典パネルを、右から出るドロワーにする)。

| 種別 | 名前 | 使っている場所 | 実装 |
|---|---|---|---|
| パーツ | ドロワー / ボトムシート | 出典の行(パネル・折りたたみ)を押すと、本文の抜粋・関連度・namespace・引用回数を右から出す。720px未満は下から出るボトムシート | `#sourceDrawer`、`openSourceDrawer()`。抜粋は `/query` の `sources[].excerpt`(先頭400文字、履歴にも残る) |
| パーツ | スケルトン | 回答の生成中、回答の形の灰色の枠を出す(動かさない) | `.msg.skeleton` |
| パーツ | トースト | 評価・コピー・お気に入り・同期の完了と失敗 | `showToast()` |
| パーツ | チップ | チャットの検索対象namespaceを、押して付け外し(0個 = 全DB横断) | `#nsChips`、`selectedNs` |
| パーツ | バッジ | 直近7日の同期の失敗件数を、管理タブとナレッジ登録の左メニューに小さな丸で | `setCountBadge()` |
| パーツ | エンプティステート | 履歴・お気に入りが無いとき、次の行動(チャットへ)を案内 | `renderEmptyState()` |
| 動き | タイプライター | 新しく生成した回答の文字を、最大1.5秒で順に表示(4000文字超・履歴は対象外) | `typewriter()` |
| 動き | スクロールスパイ | 管理タブの左に「このページの内容」を出し、いま見ている見出しをハイライト | `buildAdminToc()` |

- 動きの上限(2種類)を守るため、前回入れた評価ボタンの波紋(R6)と、空状態の点の漂いは外した。
