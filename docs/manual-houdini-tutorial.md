# Houdini チュートリアル生成パネル 取扱説明書

**対象:** 実証実験に参加する方（企業の技術者・学生）／ **版:** 2026-10-21

## 1. これは何か

[![チュートリアルと動画ができるまで](images/02-tutorial-flow.svg)](images/02-tutorial-flow.svg)

*図: チュートリアルと動画ができるまで。トピックを入れてから、ダッシュボードに載るまでの8段階。*

Houdini の中で、トピック（例:「煙のシミュレーション」）を入れるだけで、AI が次のものを作ります。

1. **チュートリアル:** AI が実際に Houdini のノードを組み、動かして確かめながら、手順書（Markdown）を作ります。
2. **解説動画:** 手順書とスクリーンショットから、初心者向けの説明つきの動画を作ります（音声つき）。

生成の途中で、AI は次の順で作業します。「考え方の設計 → 最小構成を少しずつ作る → 各段階で確かめる → パラメータを動かして効果を見る → 仕上げ」。仕上がった手順書には、「学ぶこと」「先に知っておく考え方」「確認ポイント」「パラメータを動かして確かめよう」「次のレッスン」が入ります。

> **ご注意:** 生成された手順・説明・動画は AI が書いたものです。**内容が正しいかは、必ずご自分で確かめてください。** 今回の実証実験は、その「使えるか・分かりやすいか」を評価していただくためのものです。

## 2. 必要なもの

| 項目 | 内容 |
|---|---|
| Houdini | 21.0 または 22.0（Apprentice・Indie・Education・商用いずれでも動きます）。企業の方は、業務で使うライセンスのものを使ってください（Apprentice は商用利用不可です）。 |
| OS | Windows 10 / 11（64ビット） |
| 接続先と鍵 | 運営からお渡しする **URL** と **API キー**（1人1つ） |
| 動画を作る場合 | **RAGReel**（動画エンジン）のインストール（[manual-ragreel.md](manual-ragreel.md)）。パネルだけでも、チュートリアルの生成はできます。 |
| ネットワーク | インターネットに出られること（AI と音声合成は、運営のサーバー経由で呼び出します） |

**インストールするものは2つだけです。** パネル（このマニュアル）と、動画エンジン（RAGReel）。音声（VOICEVOX など）は、**入れる必要がありません**。

## 3. 導入（約5分）

1. 配布された **`RAGReelTutorial-<版>.zip`** を、好きな場所に展開します。
2. Houdini を**一度起動して、終了**します（`Documents\houdini22.0` のようなフォルダを作るため。すでに使っている場合は不要です）。
3. 展開したフォルダの **`install.cmd`** をダブルクリックします。
4. 聞かれたら、URL と API キーを入れます（キーは画面に表示されません）。空のまま Enter でも構いません。あとで Settings タブでも入れられます。
5. 「完了しました」と出たら、**Houdini を起動**します。
6. ペインのタブの「＋」→「New Pane Tab Type」の中から、**RAGReel Tutorial** を選びます（Python Panel の項目にあります。見つからないときは、メニューの Windows → Python Panel も確認してください）。
7. 開いたパネルでは、**Tutorial** タブと **接続** タブ、**History** タブ、**動画** タブを使います。**Chat タブは、接続先（Cloudflare）に繋がります**（Settings タブの「モード」が cloudflare のとき）。

- 管理者権限は要りません。
- 動画エンジンを先に入れておくと、場所を自動で見つけて設定します。
- **更新するとき**は、新しい zip で同じ手順をやり直すだけです（設定は残ります。元の設定ファイルは、同じフォルダに `.backup_日時` として残ります）。

> インストーラーは、設定ファイル（`C:\Users\<あなた>\.houdini\rag_chatbot_config.json`）に、接続先と動画エンジンの場所を書きます。API キーも、このファイルに保存されます。**他の人と共有するPCでは、ご注意ください。**

## 4. はじめての1本

1. パネルの **Tutorial** タブを開きます。
2. **トピック**に、作りたいものを書きます（例: `岩を地面に散らす`）。
3. **レベル**は `basic` を選びます（初めての方向け。次の節を参照）。
4. **生成**を押します。
5. 画面の進行ログが流れます。**数分かかります**（目安: 2〜4分）。途中で Houdini のシーンに、`ai_tutorial_日付_時刻` というノードが作られ、AI がその中で作業します（あなたのシーンの他の部分には触りません）。
6. 完了すると、**プレビュー**が出ます。「**レッスン品質チェック: ○○/100**」の行も出ます（次の節）。
7. 内容を読んで、よければ **保存**を押します。`ドキュメント\RAGReelTutorial\localRAG\tutorials\` に、手順書（`.md`）とノードグラフ（`.json`）が保存されます（場所は Settings タブの「Bridge Directory」。導入時に自動で設定されます）。
8. 保存すると、続けて**動画の生成**が始まります（動画エンジンが入っているとき）。

## 5. 画面の説明（Tutorial タブ）

| 項目 | 説明 |
|---|---|
| トピック | 作りたいもの、学びたいことを、1行で。 |
| 生成条件 | 守ってほしい条件（例: `Pyroを使うこと`、`ノードは5個以内`）。最優先で守られます。 |
| レベル | `basic` / `applied` / `advanced`。**学習の道すじ**（レッスン1→2→3）です（下の表）。あわせて、**説明の言葉の難しさと深さも段階に合わせて変わります**（basic: 用語を説明しながら／applied: 仕組みと理由まで／advanced: 専門用語のまま設計判断まで）。 |
| 3段階連続生成 | チェックすると、basic → applied → advanced を続けて作り、自動保存します（**費用は約3倍**です）。 |
| 参考画像を追加／クリップボードの画像／クリア | 完成イメージの画像。AI が、見た目の特徴を読み取って、近づけます。画像は AI に送られます。 |
| 対象モデルを選択 | アニメーション・リギング用に、FBX などのモデルを指定します。**ファイルの中身は送られません**（AI は Houdini の中で読み込みます）が、**ファイル名と場所（パス）は、AI への指示に含まれます。** |
| 生成 | 開始します。 |
| 保存／破棄 | プレビューを保存、または捨てます。**保存を押すまで、ファイルは書き込まれません。** |
| サンドボックス削除 | 生成のために作られた `ai_tutorial_…` ノードを消します。 |

### レベルの意味

| レベル | レッスン | 目的 |
|---|---|---|
| basic | 1: 「〜とは？」と、最小の作り方 | 考え方をつかみ、3〜6ノードの最小構成を作れるようになる |
| applied | 2: 動かして理解する | パラメータを動かして効果を体験し、見た目をコントロールする技を足す |
| advanced | 3: 実務で使える形にする | 再利用（パラメータの整理・バリエーション）と、ゲームエンジンへ渡すときの注意点 |

## 6. 生成結果の読み方

手順書は、次の順に並びます。

`概要 → このレッスンで学ぶこと → 先に知っておく考え方 → 手順（各章の終わりに ✅ 確認ポイント）→ パラメータを動かして確かめよう → 仕上げ → コード・ノード構成 → ハマりポイント → 応用・発展のヒント → 次のレッスン → 参考`

- **✅ 確認ポイント:** 「ここで〇〇が見えれば正しい」という、自分で確かめるための目印です。
- **パラメータを動かして確かめよう:** AI が実際に値を変えて、結果を確かめたものです。「**設計段階の予想です**」と書かれているものは、確かめられていません。ご自分で試してください。
- **レッスン品質チェック（0〜100点）:** 手順書に、上の要素が揃っているかを自動で採点したものです。**内容が正しいかの点数ではありません。** 「不足: …」に、足りない要素が出ます。
- **打ち切り:** 「この生成は途中で打ち切られました」と出たときは、未完成です（反復の上限・費用の上限・予算の不足など）。

## 7. 解説動画

[![動画ができるまで（RAGReel）](images/05-video-flow.svg)](images/05-video-flow.svg)

*図: 動画ができるまで（RAGReel）。手順書から、音声つきの WebM を作り、ダッシュボードに載せる。*

保存すると、自動で動画が作られます。**プログレスバー**に、全体の進み具合が出ます。

| 段階 | 目安 |
|---|---|
| 台本づくり（AI が、初心者向けの説明を書く） | 約30〜60秒 |
| 動画エンジンの起動・スライドの構成 | 数秒 |
| 音声の作成（スライドごと） | 約1〜2分 |
| 描画 | 約1分 |

- 完了すると「**▶ プレビュー再生**」と「**外部プレイヤーで開く**」が使えます。**うまく再生できないときは、外部プレイヤーを使ってください。**
- **動画タブ**に、作った動画が並びます。
- **音声:** 運営のサーバー経由の Google の音声合成を使います。進行欄に「音声: Google Cloud TTS:…」と出ます。サーバーに繋がらないときは、VOICEVOX（入っていれば）、なければ Windows 標準の音声に切り替わります（「従来の音声（SAPI）」と出ます）。
- 動画ファイルは、動画エンジンのインストール先の `output\videos\` に保存されます。

### ダッシュボードの「動画」ページに載せる

Houdini の中や自分のPCで確認しているだけでは、**ダッシュボードの動画ページには載りません**。載せるには、動画をギャラリーへアップロードします。

1. **接続** タブの「動画・ギャラリー」に、運営から受け取った **ギャラリーのURL** と **アップロードトークン** を入れて、「設定を保存」。
2. 「動画の生成が終わったら、自動でギャラリーへアップロードする」にチェックが入っていれば、**これから作る動画は、できあがると自動で送られます**。
3. **すでに作った動画**は、**動画**タブで、動画を選んで「**選択をダッシュボードへ**」、または「**未アップロードをすべて**」を押します。すでに載っているものは、飛ばされます（やり直しても、重複しません）。
4. 結果は、動画タブ上部の1行に出ます（例:「3 本をアップロードしました」）。

- アップロードできる動画は、**約95MBまで**です（超えると、理由つきで、その動画だけ飛ばされます）。
- アップロードトークンは、ギャラリーに動画を載せる権限そのものです。**他の人に渡さないでください。**
- 失敗しても、ローカルの動画は消えません。もう一度押せば、続きから送られます。
- 台本の文章は、AI が書いたものです。保存フォルダの `<名前>_video_script.json` を直して、再生成することもできます。

## 8. 履歴と評価（ご協力のお願い）

**History** タブに、過去の生成物が並びます。選ぶと、ノードグラフが見られます。

**評価をお願いします。** 各生成物に、👍／👎 と、理由のタグ、一言メモを付けられます。

- 企業の方: 「実務で使えるか」（手順の正しさ、再現できるか、時間の節約になるか、動画の質）
- 学生の方: 「分かりやすいか」（初心者にも理解できるか、学習に役立つか、動画の説明は十分か）

評価は、運営のサーバーに送られます（送る内容は次の節）。取り消しもできます。

- **送れなかった評価**（通信エラーなど）は、手元に「未送信」として残り、**次にパネルを開いたときに自動で再送**されます。
- History の「**未評価のみ**」で、まだ評価していないものだけを絞れます。「**評価の集計**」で、これまでの評価をまとめて見られます（CSV で書き出せます）。
- 実証実験に参加する人は、接続タブの「実証実験に参加する」を入れると「**課題**」タブが出ます（使い方は [user-manual.md §9.5](user-manual.md)）。

## 9. 費用と上限

- 1回の生成（チュートリアル＋動画）に、AI の利用料がかかります。**ご負担は、ありません。** 運営が、1人ごとに**利用の上限（予算）**を設定しています。目安は、**10回分前後**です。
- 上限に達すると、「予算の上限に達しています」と出て、それ以上は生成できません。運営にご連絡ください。
- 音声は、1日の文字数に上限があります（動画10本前後で足ります）。上限に達すると、その日は別の音声に切り替わります。
- 「3段階連続生成」は、1回で3本分を使います。

## 10. データの扱い（送られるもの）

| 送り先 | 内容 |
|---|---|
| 運営のサーバー → AI（Anthropic） | トピック、生成条件、参考画像、Houdini の作業の内容（ノード名・パラメータ・実行結果・確認用のビューポート画像）、保存した手順書（台本づくりのため） |
| 運営のサーバー → 音声合成（Google） | 動画のナレーションの文章（台本の文）だけ |
| 運営のサーバーに保存 | あなたの評価（👍👎・タグ・メモ）、生成の自動指標（反復回数・費用・点数など） |
| あなたの PC だけ | 手順書・ノードグラフ・動画・スクリーンショット |

- **社外秘のデータ・モデル・画像は、入力しないでください。**
- 学生の方の評価と利用記録は、**成績とは無関係**で、**匿名の ID** で扱います（詳細は、運営からの説明書をご確認ください）。

## 11. 困ったとき

| 症状 | 対処 |
|---|---|
| パネルが見つからない | Houdini を再起動。メニューの Windows → Python Panel を確認。`install.cmd` をもう一度実行。 |
| 「URL/APIキーが未設定です」 | 接続 タブの URL / APIキー を入力して、保存。 |
| 「予算の上限に達しています」（429） | 運営にご連絡ください。 |
| 生成が途中で止まる | ログの最後の行を確認。反復の上限（80回）・費用の上限・予算のどれかです。もう一度、トピックを絞って試してください。 |
| 動画が作られない | 接続 タブの「動画・ギャラリー」の Video Factory exe パス（`video_factory_exe_path`） が正しいか確認（RAGReel をインストールすると、自動で入ります）。 |
| 「認証エラー: アップロードトークンが正しくありません」 | 接続 タブの、ギャラリーのアップロードトークンを確認。 |
| 動画が、ダッシュボードに載らない | 接続 タブの、ギャラリーのURL・トークンを入力して保存 → 動画タブで「選択をダッシュボードへ」。自動で送られるのは、**URLとトークンを入れたあとに作った動画**だけです。 |
| 動画の音声が従来の音声（SAPI） | URL・APIキーが入っているか、1日の音声の上限に達していないかを確認。 |
| チャットを使ったあと、パネルの幅が動かせない | 最新版のパネルで直っています。`install.cmd` で更新してください。 |
| 煙などが映らない動画になる | 生成の仕様上、見えない状態で確定しないよう直してありますが、起きたら、評価の「動画が悪い」と、メモでお知らせください。 |

**運営への連絡の際は、**保存フォルダ（`ドキュメント\RAGReelTutorial\localRAG\tutorials\`）の `<名前>_video_factory.log`（動画の問題）と、`ドキュメント\RAGReelTutorial\logs\tutorial_agent\` の最新の `.jsonl`（生成の問題）を添えていただけると、原因を調べられます。キーは含まれません。

## 12. アンインストール

展開したフォルダで、次を実行します（Houdini を閉じてから）。

```
install.cmd -Uninstall
```

パネルのファイルと、Houdini のパッケージ登録を消します。設定ファイル（`.houdini\rag_chatbot_config.json`）は残ります（キーを消したいときは、このファイルを削除してください）。動画エンジンは、Windows の「アプリと機能」から、RAGReel を削除します。
