# パネルの整理・動画の投稿・ビューポート画像の修正（前と後の差）

**日付:** 2026-11-19　**対象:** Houdini パネル（RAGReel Tutorial）、動画エンジン・ギャラリー（RAGReel）

2026-11-18 の依頼（アイコン・タブ・Guide の強調・表示の切り替え・追加指示・動画が投稿されない・スクショのずれ）に対応した記録。
**実機（Houdini・本物の R2）では、まだ確かめていない**。Houdini の API の呼び出しは、偽の `hou` で確かめた。

## 1. 原因を確かめたもの（実機の記録から）

### 1.1 動画が、ギャラリーに投稿されない
- 記録: `energy-effect-layer-design_20261118_video_factory.log` に、`Cloud gallery upload failed ... Payload Too Large`。動画は 114.7MB（1390 秒・1080p30）。
- 原因: 1 回の POST で送るため、Cloudflare の本文の上限（100MB）を超えた。Worker も、動画を全部メモリに読む（上限 128MB）。**フル HD・30 fps にした（11/17）ことで、約 1000 秒以上の動画が超えるようになった。**
- もう 1 本（`spiral-glow-...`、858 秒）は、アップロードの試みが記録に無い（そのときは、自動アップロードの設定が入っていなかったと見ている）。
- さらに、失敗は**ログにしか残らず**、パネルは「完了」と出して終わっていた。

### 1.2 ビューポート画像が、手順と合っていない・同じ画像が続く
- 記録: 58 手順のうち、ビューポート画像の md5 が同じものが、最大 15 枚続いた（球のまま、など）。
- 原因 1: 表示フラグを動かすのは、末端への接続・cook の成功・view_viewport だけで、**ノードを作る・値を変える手順では動かさなかった**（`houdini_tools.py`）。
- 原因 2: 利用者のほかのオブジェクト・前の生成のサンドボックスの表示が入ったままで、ビューポートに重なる。
- 原因 3: 縦長のペイン（1920x2132）で撮った画像が、そのまま動画に入り、16:9 の枠の中で小さく、左右に黒い帯が出た。

### 1.3 手順の本文に「バックスラッシュ + n」が出る
- 記録: `energy-effect-layer-design_20261118.md` の手順が 1 行のままで、2 文字の改行が 119 個。モデルが、改行を二重にエスケープして送った。

## 4. 実機で試すもの・まだのもの

- **反映**: パネルは、`uv run python houdini/deploy_panels.py 22.0 --pypanel` で、Houdini の場所へ配置する（まだ配置していない）。動画エンジンは、インストーラーの作り直しが要る。ギャラリー Worker は、**デプロイが要る**（先に Worker を出さないと、新しい動画エンジンの「分けて送る」が 404 になる。古いエンジンは、これまでどおり）。
- 実機で確かめるもの: ParameterEditor の `scrollTo` / `moveFocusTo` の見え方、表示フラグの切り替えと、ビューポート画像、メニューのアイコン、「はじめに」のアイコンタブ、本物の R2 のマルチパート。
- 追加指示は、前のノードを引き継いで編集するのではなく、**新しいサンドボックスで作り直す**（前の結果は、保存していなければ破棄される）。
- すでに投稿に失敗した 2 本（1390 秒・858 秒の動画）は、新しい版を入れたあと、Movie タブの「未アップロードをすべて」で送れる。
- 表示を切ったオブジェクトは、生成・案内のあと、切ったまま。戻すのは、Guide の「案内の設定」の「ほかのオブジェクトの表示を元に戻す」。
